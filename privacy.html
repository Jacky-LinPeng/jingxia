隐私政策

静匣隐私政策 生效日期：2026 年 10 月 19 日 开发者：Peng Lin 1. 本地处理 静匣无需注册。你选择的照片、视频、文件、名称和文件夹信息仅用于本机加密保存、浏览和管理。开发者不收集或接收这些内容，也不接收口令或密钥。 2. 可选广告与选择权 可选广告启动前，系统允许请求时，应用通过原生 iOS App Tracking Transparency（ATT）请求权限，不使用自定义跟踪许可弹窗。拒绝或限制跟踪不会停用广告：应用在无法访问 IDFA 的情况下请求非个性化广告，仍须满足 UMP 同意要求和广告库存条件。系统跟踪决定明确后，才启动 Google Mobile Ads 和 UMP。发布商第一方 ID 和发布商广告个性化均关闭，每次请求也标记为非个性化广告。我们不使用指纹识别或其他标识符绕过拒绝跟踪的决定。可在「设置 → 广告」单独停用广告。UMP 管理其他适用的隐私选择，不能替代 ATT。 停用广告或撤销权限会停止后续同意及广告请求，但不能清除 Google 已处理的数据；已启动的 SDK 可能完成进行中的处理。 启用广告后，Google 可能处理 IP 地址（用于估算大致位置）、设备或应用标识符、已观看的广告及互动、崩溃日志与性能诊断，用于广告、分析和防欺诈。这些数据发送至 Google，并可能依其政策与广告服务提供方共享。我们请求非个性化广告，停用发布商第一方 ID，在启动任一 SDK 前通过 iOS 请求 App Tracking Transparency 授权。非个性化广告仍可能使用标识符和本地存储，不代表零数据收集。我们不会向两个 SDK 提供保险箱文件、文件名、口令或加密密钥。 前两次冷启动不展示开屏广告，之后开屏广告间隔至少四小时。在设置中自愿观看激励广告，仅在 SDK 确认奖励后获得 24 小时免开屏广告；提前关闭或广告不可用不会获得奖励。展示广告前会锁定保险箱。 Google 按其隐私政策管理收到的数据的保留和删除。你可使用 Google 隐私控制并联系 Google 行使访问、删除等适用权利。停用广告或卸载应用不会自动删除 Google 的数据，开发者无法代为删除。对于开发者处理的数据或相关隐私权利，请通过下方支持页联系 Peng Lin；请勿在公开 Issue 中发布敏感信息。Google 隐私政策：https://policies.google.com/privacy Google 合作伙伴数据用途：https://policies.google.com/technologies/partner-sites 3. 系统权限 照片与文件通过系统选择器读取你选择的项目。拍照时请求相机权限；Face ID 由系统验证，应用不获取人脸模板。拒绝可选权限不影响其他功能。 4. 备份与导出 默认不提供云同步。你可主动将加密备份或明确导出的明文副本保存到其他位置，目标服务可能自行处理和同步数据。iOS 系统备份和文件提供方由 Apple 或相应服务提供方管理，排除备份标记不构成绝对保证。 5. 保留与删除 资料保留至你主动删除或卸载。删除不会清除以前导出的副本或外部备份。没有可用密钥和备份恢复凭据时，开发者无法恢复资料。 6. 外部支持网站 仅在你主动打开帮助链接时访问 GitHub Pages。GitHub 可能按其政策处理 IP 地址和访问日志；页面不含我们添加的广告、跟踪或统计脚本。请勿在公开支持渠道提供私密文件、口令或恢复凭据。 7. 联系与政策更新 通过支持页的 GitHub Issue 联系开发者，公开内容请勿包含个人隐私。政策更新会在应用与隐私页面发布。 支持：https://jacky-linpeng.github.io/jingxia/support.html 在线政策：https://jacky-linpeng.github.io/jingxia/privacy.html
