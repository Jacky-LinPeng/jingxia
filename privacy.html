隐私政策

静匣隐私政策 生效日期：2026 年 10 月 8 日 开发者：Peng Lin 1. 本地处理 静匣无需注册。你选择的照片、视频、文件、名称和文件夹信息仅用于本机加密保存、浏览和管理。开发者不收集或接收这些内容，也不接收口令或密钥。 2. 无广告与跟踪 本应用无广告、无内购、无第三方分析 SDK，不建立用户画像，不主动上传使用记录或崩溃日志。 3. 系统权限 照片与文件通过系统选择器读取你选择的项目。拍照时请求相机权限；Face ID 由系统验证，应用不获取人脸模板。拒绝可选权限不影响其他功能。 4. 备份与导出 默认不提供云同步。你可主动将加密备份或明确导出的明文副本保存到其他位置，目标服务可能自行处理和同步数据。iOS 系统备份和文件提供方由 Apple 或相应服务提供方管理，排除备份标记不构成绝对保证。 5. 保留与删除 资料保留至你主动删除或卸载。删除不会清除以前导出的副本或外部备份。没有可用密钥和备份恢复凭据时，开发者无法恢复资料。 6. 外部支持网站 仅在你主动打开帮助链接时访问 GitHub Pages。GitHub 可能按其政策处理 IP 地址和访问日志；页面不含我们添加的广告、跟踪或统计脚本。请勿在公开支持渠道提供私密文件、口令或恢复凭据。 7. 联系与政策更新 通过支持页的 GitHub Issue 联系开发者，公开内容请勿包含个人隐私。政策更新会在应用与隐私页面发布。 支持：https://jacky-linpeng.github.io/jingxia/support.html 在线政策：https://jacky-linpeng.github.io/jingxia/privacy.html
